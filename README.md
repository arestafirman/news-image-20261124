# The World in One Day — Tuesday 24 November 2026

One image summing up the world's news of Tuesday 24 November 2026: 36
stories across 8 regions — 3 illustrated hero scenes, 10 illustrated tiles,
a world map with numbered pins, a UTC timeline, and a DATE CHECK box listing
the stories left out because they happened on an earlier day.

Every story here happened, or was first reported, on Tuesday 24 November
2026. Sources are named beside each story. All artwork is drawn in code
(original procedural drawings, no photos, no external assets).

## Run

```sh
python3 generate_image.py   # renders entry.png (1024x1024)
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) copies `entry.png` to
`$MAKEFUN_OUTPUT_DIR/entry.png`. Rendering is deterministic: two runs
produce byte-identical output.
